# 指标与数据口径

## 使用约定

围绕本轮目标与指定成果推进。区分现状、方案、已确认决定和待补信息；沿用已有决定，集中处理关键分歧。结论前置，检查强度与改动相称。

## 层级与按需参考

本技能属于数据产品专题层。数据来源、快照差分和查询能力需要核对时读取 [数据调研与核对](references/数据调研与核对.md)；需要衔接页面设计、原型或文档时读取 [报表方案与交互](references/报表方案与交互.md)。

餐饮任务读取 [餐饮业务参考](../product-workflow/references/餐饮业务/业务参考.md) 中与本轮相关的内容；其他行业采用当前项目的角色、对象、竞品和资料。架构与能力记录按产品分别维护。

## 必要输入

业务对象、原始记录或字段资料、当前确认规则及查询条件；取值未知时记录来源缺口。

## 执行步骤

1. 先定义业务对象、一行粒度和关联键，说明每条原始记录代表什么。确认一对多关系再设计汇总，避免联接重复计数。
2. 为每个相关字段记录完整名称、含义、来源、计算过程、单位、状态范围、时间归属、筛选影响和合计方式。显示值与内部计算变量分开命名说明。
3. 从上游输入如何产生追到结果；给定样例值只能证明该输入之后的过程。优先复用已确认机制，输入调整不自动触发算法重设计。
4. 涉及时间时核对业务对象的时区、统计周期边界、动作时间与归属时间。跨地区、跨午夜、夏令时按实际查询与计算需要展开，明确时长计算采用的时间基准。
5. 涉及金额时核对业务组成、正负方向、状态范围及汇总关系，明确精度、舍入时机和历史数据适用范围；行业检查项按相关业务参考选用。
6. 用相同原始输入计算旧值和新值，选择会改变规则的边界：阈值前后、逐笔与累计、跨日、重复记录等。仅在范围一致且指标可加时要求明细与汇总相等。
7. 法律要求与系统现状、目标产品规则分别列依据；需要法规结论时查询适用地区及有效期的权威资料。

## 输出

字段口径表、输入到结果的计算说明、关键案例及关联影响。

需要组织成果时读取 [交付模板](assets/交付模板.md)，按本轮成果裁剪填写。

## 完成标准

每个结果可追溯到原始输入或明确给定值；展示含义与内部变量清楚；跨页口径差异有业务理由。

## 常见误判

计算输入变化后直接改写既有展示字段含义；同名金额直接复用；平均值或比率直接求和。
