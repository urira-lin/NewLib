# 报表方案与交互

数据产品专题层。用于报表、分析工具及指标展示的场景、方案、原型和文档；涉及计算定义时使用 [指标与数据口径](../SKILL.md)。

## 场景与信息需求

从用户要做的判断或核对推导必需信息、维度、记录粒度和操作。先提出业务需要，再检查现有字段与数据源能否承载，记录复用、新增和待确认项。

用用户问题自上而下推维度，用真实业务行为自下而上查字段覆盖，用相关竞品研究校验信息组织。字段全集提供覆盖能力，默认列、详情列和摘要指标根据任务分别取舍。

## 竞品与信息架构

比较同类业务对象和一行粒度，再查看字段分组、时间口径、筛选、下钻与导出。将竞品观察与推断分别记录，说明每个借鉴点服务什么用户任务。

确定首页摘要、完整报表、明细和导出的职责。明确指标点击进入哪里，下钻继承哪些查询条件，返回保留什么状态；按当前价值和既有能力决定信息量及改造范围。

## 关联原型

同一组原始模拟数据派生卡片、图表、明细与导出。时间、组织/业务对象、用户、分组和单位变化时，相关视图产生可辨认且一致的结果；新旧方案使用相同输入。

区分配置草稿和已保存结果，按确认规则实现应用、取消、返回和刷新。查询精度以实际结果核对，组件统一时保留各页面支持的能力差异。

## 文档与验收衔接

PRD记录字段含义、输入来源、计算过程、时间与状态范围、筛选影响及汇总方式，按需要引用正式字段表。展示字段与内部变量分别表达。

业务规则变化后同步受影响的摘要、字段定义、案例、原型计算、功能清单和验收。跨页口径相同或不同，都要有对应的业务依据。

验收覆盖关键查询条件、输入到结果、明细汇总和跨页条件继承。验证按实际执行层级记录，开发交接沿用项目的确认与归档流程。
